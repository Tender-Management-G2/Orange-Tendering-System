# Art direction — From Paper to Signal

An Orange-inspired academic system, not an official Orange product. Use the existing permitted brand assets only; no claim of affiliation.

## Registration / Paper Genesis
A modern editorial drawing, not a photograph of a desk. Start with an ivory canvas (#F8F5EF), ink (#242321), an exact orange accent (#FF7900, proposed), and warm paper shadow (#D6C9B8). Delicate 1.5–2px linework and quiet typography. No fixed desktop photo, stationery stock imagery, gratuitous glass, neon, or floating UI stickers. Use generous negative space. The form and scene are peers, not an oversized wallpaper. Desktop form approximately 42%, scene 58%; on mobile compact illustration before or after the form; the form never scrolls inside a trapped pane.

At idle the scene is genuinely planar: a single outlined sheet, visible fold scores, and one orange registration mark. The identity card is drawn out of the sheet, not a floating DOM element. A hinged sleeve seals only when the password form is locally valid (not a server verification claim). When company details begin, the same sheet tilts into a three-quarter view and gains thickness. Hinged walls unfold from the sheet, with connected pivots. The roof and signage form last. Every later prop belongs to the same model or validated layer. The orange square survives as the continuity marker from sheet to building to ID.

Production look: tactile matte paper, restrained ambient occlusion, consistent paper thickness, subtle bevels, one soft key light and one fill. Use orthographic or restrained perspective camera. No photoreal desk, no depth-of-field that obscures forms.

## Login / Orange Signal
Near-black graphite (#151515), off-white (#F8F5EF), single Orange accent. Inspired by telecom hardware, not a generic node network: SIM contact pads, fiber-optic cable cross-sections, printed circuit traces, precision-machined authentication core. One curved cable wraps around a compact square module; initial appearance is a clean 2D technical outline, then forms into a physically credible real 3D assembly. An orange light pulse travels along the cable only on valid transitions. Do not use brand-restricted images without permission.

Email completes address registration visually; password mechanically aligns the contact plate (never render any secret). After server accepts credentials, internal roles continue normally. Supplier account enters a second stage: the core opens into a six/eight-segment optical aperture; two options are presented as real UI controls outside canvas, Face available if configured, Fingerprint disabled / Coming soon. Face unlocks a live video reveal inside a physically aligned aperture. On real successful verification an orange pulse travels out of the module and resolves into a workspace transition. Failed checks never pulse success. No generic giant lock, rainbow glow, green fake face scan, or tangled decorative wires.

## Shared rules
Single visual grammar: square marker, exact edge line, restrained orange, mechanical folds. One persistent scene graph per journey. Position controls using the scene projection or render them within the same actual geometry; no disconnected floating cards. Motion is paced and interruptible; do not create visual clutter. No fake camera, no photographed face used as a stand-in in production; use abstract faces in design/QA. Show real status as accessible text outside canvas. Support reduced motion with static endpoint compositions.
