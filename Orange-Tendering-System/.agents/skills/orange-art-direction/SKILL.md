# Art direction gate
Read `design/ART_DIRECTION.md` and `design/REFERENCE_BRIEFS.md` in repository root. Inspect the reference PNG/SVG boards at their actual paths. Identify what is reference-only versus runtime geometry. Never use a desk photo or full-scene generated bitmap as runtime backdrop. Never use floating HTML cards over a static scene. Ensure every asset shares scale, camera and origin. Registration begins genuinely flat and only acquires depth at company step. Login uses physical telecom components rather than a generic node network. Provide keyframes and seek user approval at G1 before integrated code. Preserve the existing functionality and approved brand/asset permissions. Follow `design/QA_GATES.md`; if references, tools, or approval are unavailable, report the blocker, do not silently choose a cheaper style.
