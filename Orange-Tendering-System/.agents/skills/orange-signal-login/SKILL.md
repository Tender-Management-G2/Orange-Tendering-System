# Login motion workflow
Read `design/ART_DIRECTION.md`, `design/MOTION_SPEC.md`, `design/ASSET_MANIFEST.md`, `design/QA_GATES.md` at repository root. Apply shots L00–L07. Use one compact core, one bounded cable path, physical aperture segments and minimal Orange accent. Draw traces, then construct physical assembly. Move a pulse along the cable rather than adding network dots or generic locks. Camera view is aligned to the actual aperture, not a floating video. Login form initially email/password only. Supplier method selection appears after server confirms credentials and role; employees follow existing policy. Fingerprint is explicitly disabled, no bypass. Only actual real server verification unlocks the final sequence or session. Pending suppliers cannot participate. No secrets or biometric images in QA. G2 is isolated synthetic lab only; no production login modifications without user approval. If provider or device unavailable, report pending.
