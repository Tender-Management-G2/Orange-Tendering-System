# Design-to-code delivery map

| Iteration | Visible acceptance artifact | Implement only after |
|---|---|---|
| A — IA & Shell | Five exclusive tabs; sidebar collapse; shared filter bar; shared voice dock | Existing layout/roles/routes inspected |
| B — Suppliers | Cinematic 3D universe + 2D fallback; KPI; tiny market snapshot; voice dock | Approved A screen and data contract |
| C — Tender | Search/select any authorized tender, timeline and bids visualization | Authorization and tender lifecycle timestamps verified |
| D — Forensics | Findings list + evidence graph/details, not a second supplier universe | Existing detectors and provenance found |
| E — AI Studio | Declarative charts/tables/cards generated inside conversation; upload/extract/export | Current chatbot tools and document services audited |
| F — Polish | Arabic/English, responsive, light/dark, performance, minimal browser smoke | Each tab visually accepted |

At each iteration: run app -> capture ONE useful viewport + if necessary ONE detail -> inspect legibility, hierarchy and spacing -> correct. Avoid generating huge test suites or a long changelog before design quality is proven.
