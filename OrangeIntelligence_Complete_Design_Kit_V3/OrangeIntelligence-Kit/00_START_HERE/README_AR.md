# Orange Intelligence — Complete Redesign & Implementation Kit (NEW)

**هدف الحزمة:** تنفيذ واجهة موحدة لـ AI Intelligence داخل مشروع ASP.NET Core MVC الحالي، مع خمسة تبويبات **متبادلة وليست متراكبة في صفحة واحدة**، وهوية بصرية عالية الجودة، وتحويل الوظائف الموجودة إلى تجربة مقروءة ومتسقة. المركز الإبداعي: تبويب **Suppliers** وشبكة الموردين ثلاثية الأبعاد والمساعد الصوتي.

## ابدأ هنا
1. فك الضغط **خارج** `wwwroot` في مجلد مشروع الحل بجوار `.slnx`، ولا ترفع محتوى الحزمة إلى Git إلا عند اتخاذ قرار واعٍ بملفات Skills/التوثيق المطلوبة. لا تنسخ PDF أو الصور إلى `wwwroot` تلقائيًا.
2. افتح Claude Code من **مجلد المستودع المقصود**، ثم أرسل `MASTER_PROMPT.md` أو أشر إلى مساره المطلق (لا تعتمد على `@` لاكتشاف ZIP).
3. اجعل Claude يقرأ `01_REQUIREMENTS` و`02_PRODUCT_BLUEPRINT` و`04_ENGINEERING`, ثم الصور بحسب التبويب المحدد. الصورة المولدة *إلهام بصري* وليست مخطط بيانات صحيحًا.
4. نفذ أولًا **Suppliers كتَبويب مستقل**، وراجع جودة الشاشة قبل الانتقال إلى بقية التبويبات. لا تعِد بناء الباك إند الذي يعمل مسبقًا.
5. المهارات داخل `07_CLAUDE_SKILLS/.claude/skills` قابلة للنسخ اختياريًا عبر `08_TOOLS/Install-Skills.ps1`؛ لا تُثبَّت تلقائيًا بمجرد وجود ZIP.

## تصميم غير قابل للتفاوض
- تبويبات `Overview | Suppliers | Tenders | Forensics | AI Studio` تستبدل محتوى بعضها بدل تكديس الصفحات عموديًا.
- لا تكرر Supplier Universe في Tenders أو Forensics ولا تعرض الأقسام الخمسة أسفل بعضها.
- أقصى **4 KPI رئيسية** على رأس التبويب افتراضيًا؛ التفاصيل داخل Drill-down أو Details.
- Supplier Universe هو المشهد الأهم: كروي، حي، ثلاثي الأبعاد، بوضوح مقروء، حركة دائمة متزنة، واستكشاف دقيق 2D/Table عند الحاجة.
- مساعد صوتي واحد مستمر عبر التبويبات؛ واجهة مختصرة داخل Suppliers، والتوسعة عبر AI Studio أو Expanded Voice.
- صلاحيات المستخدم وتقييد المعلومات تتم في الخادم قبل أن تصل إلى AI أو الرسومات أو التصدير.
- صور المرجع قد تتضمن **قيمًا تمثيلية وغير واقعية**؛ الأرقام تُجلب من البيانات المصرّح بها فقط.

## حدود المشروع
مشروع أكاديمي بفريق من سبعة وأعداد قليلة من المستخدمين والموردين. لا تُدخل Microservices أو Vector DB أو نموذجًا جديدًا أو قاعدة بيانات ثانية دون إثبات الحاجة. استخدم Ollama/Qwen/Whisper/Piper الموجود؛ اختبر إمكانية الاتصال ولا تفترض أنها تعمل في جهاز الزملاء.

## ترتيب الملفات
- `MASTER_PROMPT.md`: أمر التنفيذ الرئيسي.
- `01_REQUIREMENTS/`: مستند PDF الأصلي والمتطلبات العشرة والتتبع.
- `02_PRODUCT_BLUEPRINT/`: الهندسة المعلوماتية والفلاتر والتبويبات والنصوص.
- `03_VISUAL_REFERENCES/`: صور مستقلة لكل تبويب وحالة، مع دليل استعمال.
- `04_ENGINEERING/`: واجهات البيانات و3D وVoice وGenerative UI والأمان.
- `05_DESIGN_SYSTEM/`: Tokens ومقاييس الخطوط والحركة.
- `06_ACCEPTANCE/`: معايير القبول مع حد أقصى معقول من الاختبارات.
- `07_CLAUDE_SKILLS/`: مهارات Claude المخصصة والمستقلة.
- `08_TOOLS/`: أدوات PowerShell وملفات JSON وصيغ تجريبية.

**الملفات الأصلية** ضمن الحزمة للرجوع فقط؛ لا تضعها في البرنامج المنشور دون حاجة. راجع أولًا حالة Git والفرع والعمليات والمنافذ وقاعدة البيانات كما هي فعلًا.
