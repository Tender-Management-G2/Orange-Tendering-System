# North star: ONE active intelligence perspective, exquisite clarity

**Product:** Orange Intelligence, a shared role-authorized, bilingual, high-quality AI procurement intelligence workspace within existing ASP.NET Core MVC.
**User:** internal authorized users; **excluded:** suppliers. Academic project, small procurement dataset, ~seven-person development team.
**Outcome:** users should instantly understand the current scope and answer one relevant question, with optional deeper graph/AI exploration. A novice should understand why a line exists by clicking it.

## Absolute content rules
1. Five top-level tabs: **Overview, Suppliers, Tenders, Forensics, AI Studio**. Clicking a tab replaces main content. Do not include another tab's entire content below the fold.
2. Supplier tab: `Context filters → 4 KPIs → compact two-part Market Snapshot → dominant 3D Universe → integrated expandable voice experience → supplier-specific details ON SELECTION`. If no supplier selected, no giant empty details card.
3. Overview is a gateway, not a duplicated full analytics dashboard.
4. Tenders contains tender-by-tender lifecycle and bid analytics; NOT a second Supplier Universe.
5. Forensics uses evidence-specific visualization, not a repeat of general market charts.
6. AI Studio hosts generative chat UI and Excel/PDF intelligence; same ongoing conversation in the entire app.
7. Reports/export are actions *within context*, not a whole redundant permanent top-level tab.
8. Sidebar can collapse to an icon rail and return; do not break existing pages' navigation.
9. Readability over decoration: body ~16px, graph labels >=14px when shown at normal scale, consistent contrast, two-thirds of the canvas available for the primary visualization. No microscopic names.
10. Data integrity: sources authorized server-side, sealed bids absent, small data honestly visualized, no fake globe geography.

## Interaction story
Open Suppliers → see four meaningful KPIs → inspect market distribution → interact with gently rotating universe → select category → camera settles and group expands → select supplier → node focus + evidence inspector + contextual charts → Ask AI to compare → get generated chart embedded inside conversation → pin/export. No page reload is required for visual transitions unless existing architecture mandates it.
