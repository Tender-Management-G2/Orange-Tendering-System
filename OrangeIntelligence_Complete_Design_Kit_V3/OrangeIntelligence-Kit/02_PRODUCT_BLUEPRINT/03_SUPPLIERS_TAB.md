# Suppliers — the signature view (NOT five pages stacked)

**Exact order within the Suppliers tab:**
1. Heading + scoped filters: `Supplier Intelligence` — date, department, category, registration/approval state, activity; advanced filters hidden in drawer.
2. 4 KPIs max: Registered, Approved/Eligible, Participating in closed rounds, Response rate (or equivalent grounded metric). Don't reuse the same number in 3 massive charts.
3. Market Snapshot (compact): Category distribution + participation/response. Charts cross-filter globe; tables accessible via focused toggle.
4. **Supplier Universe** dominates a full-width substantial view: large 3D globe composition, readable supplier identities, gentle orbit even at idle, relationship overlays progressive not permanently all links. A left compact floating controls cluster, right contextual inspector only on selection, 2D/Table switch, reset and pause.
5. **Voice** compact under / attached to universe; one expanded voice session when invoked, not unrelated giant panel on every page.
6. Supplier Details / Compare appears only when selecting or comparing; includes source-linked relevant performance and official awards if authorized; DNA on demand.

### Required experience
20 suppliers should be easy to navigate, all—including isolated suppliers—findable. Universe orbital default makes the overall ecosystem visible; it is **not the graph's true underlying spatial meaning**. A layout transition conveys category grouping, bid co-participation, tender links, or evidence. Dots colors encode category; never assume color means fraud. Dot size must have a defined metric or be uniform, not arbitrary.

### Graph state controls
`Universe | Category | Competition | Tender context | Evidence` are graph modes, not top-level page tabs. The Tender context in Suppliers is an optional graph filter, not a duplicate tender report.
`All suppliers`, a category, a selected supplier, multi-compare ≤ 5, click relationship, show path, center selected, reset.

### Key principle
When no supplier is selected, the inspector should be minimized; information should not suffocate the globe. Hover -> hint; click -> focus + details; double-click only if discoverable; keyboard equivalent mandatory. On selection, suspend auto orbit and reduce motion nearby for reading.
