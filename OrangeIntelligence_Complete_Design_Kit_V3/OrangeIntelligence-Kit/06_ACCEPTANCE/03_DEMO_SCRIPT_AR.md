# Demo to academic evaluators — five small, meaningful stories

1. **Overview:** show date/department scope, clear KPIs and lifecycle duration calculated from stored event time; open Tenders from summary.
2. **Suppliers:** show all actual authorized suppliers; gentle live 3D orbit; filter category and relation; select a supplier; demonstrate source-backed links and 2D/table fallback.
3. **Tenders:** search an authorized tender; show lifecycle from creation to winner-notification sent, bids and official outcomes; display missing data honestly.
4. **Forensics:** pick an exact document match; show one file evidence node linked to suppliers, explain methodology and alternative non-fraud explanations.
5. **AI Studio:** ask to compare 3 suppliers; show new Chart+Table+Card **inside the chat**; upload an approved sample XLSX/PDF, extract and export; voice assistant is the same session. Demonstrate blocked Supplier and read-only recommendations.

Never invent a real award or use fake supplier counts for the final demo. Use explicitly fictional isolated demo data only when real team data lack enough examples; label it `DEMO` unmistakably and keep database isolation.
