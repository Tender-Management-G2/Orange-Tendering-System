# Acceptance gate — visual FIRST, functionality truthful

A. **Structure**
- [ ] Exactly one of 5 top-level tabs active and rendered; no stacked versions of the other 4 tabs.
- [ ] Sidebar collapse expands content properly and preserves existing app pages.
- [ ] Each tab has contextual filters; active chips visible; clear/reset consistent.
- [ ] Voice/chat remains one persistent session through tabs.

B. **Suppliers visual**
- [ ] Universe is 3D and camera moves gently while idle (unless paused/reduced motion).
- [ ] No false globe geography, no fake central supplier, all authorized suppliers discoverable, isolated suppliers included.
- [ ] Click/hover/focus/drag work; relevant names readable at 100% browser zoom; selected node stable.
- [ ] Category/color/edge meaning documented; evidence lines only if records support them.
- [ ] Pause, 2D/table fallback, keyboard alternative, context inspector and return to Universe work.

C. **Other tabs**
- [ ] Tenders supports search/select **any authorized tender**, interactive timeline, permission-safe bid comparison, official outcome.
- [ ] Forensics renders detector-specific graph, evidence source references, non-accusatory descriptions and alternatives.
- [ ] AI Studio shows **custom chart/card/table inside conversation**, uploads and analyses PDF/XLSX, exports result.
- [ ] No duplicated full graph/voice/page sections; overview summaries link to owning tab.

D. **Mandatory requirements & security**
- [ ] All official AI #1..#10 individually demonstrable; read `REQUIREMENTS_MATRIX.md`.
- [ ] Supplier role denied; internal roles authorized **only** to own scope; protected file download tested.
- [ ] Sealed bid values excluded across graphs, AI, chat, export.
- [ ] No invented price, award, date, company or confidence; missing data explicit.
- [ ] AI recommendations read-only with supporting evidence.

E. **Polish**
- [ ] Both themes, Arabic and English, desktop 1440, laptop 1024, phone 390, reduced-motion.
- [ ] Voice orb reacts to actual sound, transcript readable; idle does not impersonate a live mic.
- [ ] No clipped axes, overlapping labels, hidden nav, or console exceptions.
- [ ] Side-by-side screenshots checked at normal viewing scale, not just a passing compiler.
- [ ] No unnecessary schema changes, no commit/push without approval.

**Focused checks only:** do not spend user budget on a full rewrite of tests unless the changed surface requires it. Existing Radar regression should stay intact.
