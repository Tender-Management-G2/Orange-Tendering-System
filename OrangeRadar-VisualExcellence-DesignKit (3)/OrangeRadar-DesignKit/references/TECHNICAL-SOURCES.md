# Technical references (official docs, curated)

These are links, not bundled vendor source or third-party skill code. Use existing installed versions first. Read targeted docs as necessary; none require adding a library merely because it is linked.

- ECharts handbook: https://echarts.apache.org/handbook/en/

- Media capture and permissions: https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia
- Reduced motion: https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/prefers-reduced-motion
- Playwright .NET screenshot capture: https://playwright.dev/dotnet/docs/screenshots
- Playwright .NET library setup: https://playwright.dev/dotnet/docs/library
- Ollama local API docs: https://docs.ollama.com/
- Whisper.net: https://github.com/sandrohanea/whisper.net
- Piper: https://github.com/OHF-Voice/piper1-gpl
