## 4. The flagship: Market Network
Default to ALL in-scope suppliers in Category View, including suppliers without any recorded links. Our datasets are small; show individual names and nodes by default. Category membership is registered classification, not proof of a relationship. No artificial central “All Suppliers” hub. No fake connections, ownership, geodata, or risk scores. Four semantic views (Category, Competition, Tender, Forensic) are distinct layouts/projections of authorized data; use separate relationship filters. Stable IDs, smooth animated repositioning and selection persistence. Category clusters use readable translucent boundaries, small icons and concise labels. Competition view groups by shared closed-round participation (deterministic and explainable). Tender view shows actual supplier–tender/round incidence; forensic view displays only supported review signals by default plus useful context on demand. Node positions and size must be legible; color indicates category, shape indicates entity type, size indicates a defined metric. Gray ordinary links, amber labeled review signals, orange selected paths. Cross-category links exist only if actual underlying supplier links exist. Aggregation must expose supporting records. See `specs/02-NETWORK.md` for graph data contract and behavior.

Make this graph more polished than the reference images: improve node iconography, hit areas, label placement, spacing, cluster boundaries, edge routing, selected states, path explanations, semantic zoom and progressive reveal. Build a beautiful all-market canvas, compact legend and filters, zoom/pan, fit, minimap if accurate, fullscreen, reset, path selection, table fallback, export, and reversible drill-down. When a group is clicked animate toward it, expand its members and open the inspector. When a supplier is clicked highlight neighbors, retain market context, and allow deeper expansion. When an edge is clicked show why it exists and its supporting records; never fake a link. Multi-select comparison updates other sections. Use real graph interactions, not static image/canvas mockups. Respect reduced motion and avoid endless physics drift.
